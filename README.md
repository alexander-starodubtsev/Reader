# Reader
Краткое описание проекта:
GoodReader - это приложение для удобного чтения книг

О проекте:
Это приложение помогает читать книги регулярнее, удобнее и позволяет совершенно любую книгу, скаченную в других источниках добавить к себе в библиотеку

Возможности:
-Авторизация
-Серия дней(чтение через приложение продлевает серию)
-Конвертация из PDF расширения в FB2 или EPUB
-Удобное переключение между чтением и прослушиванием книги с сохранением прогресса
